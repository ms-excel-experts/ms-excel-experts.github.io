## Maintain this site

This is a static HTML site with no build step, external scripts, tracking or form backend.

- Edit `index.html` to update the page text, links and styling.
- Replace a PNG with the same filename to update a showcase preview.
- In repository **Settings → Pages**, publish from **main / (root)**.
- Preview locally with a static HTTP server, then commit the updated files to `main`.

The main business website remains [ms-excel-experts.com](https://ms-excel-experts.com/).
